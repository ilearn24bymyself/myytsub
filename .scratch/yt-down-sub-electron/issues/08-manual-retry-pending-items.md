# 08: 手動重試「待重試」項目

**What to build:** 使用者可以在畫面上看到目前所有 `pending-retry` 的項目，並主動觸發「重試」，這些項目會重新進入下載佇列，照正常流程處理（可能再次成功、再次失敗、或再次被限流跳過）。系統不會自己自動重試，一定要使用者主動觸發。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 畫面上能列出目前狀態為 `pending-retry` 的項目
- [ ] 使用者觸發重試後，這些項目重新變成 `pending` 並依序進入下載佇列處理，跟一般新加入的項目走同一套流程（含票 04/06/07 已驗證過的循序、隔離、限流偵測行為）
- [ ] 沒有被觸發重試的 `pending-retry` 項目，不會自己被系統重新嘗試
- [ ] Orchestrator 的 `unittest` 測試涵蓋「觸發重試後項目重新進入佇列並被處理」這個行為
