# 09: 取消進行中的下載

**What to build:** 使用者可以取消一個目前正在下載（`running`）的項目。取消後該項目停止，佇列裡其他項目（包含正在等待中的 `pending` 項目）不受影響，繼續照原本的循序規則處理。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 畫面上對一個 `running` 的下載項目可以按下取消
- [ ] 取消後該項目的狀態變成一個能清楚識別「使用者取消」的終態（不與 `error` 或 `pending-retry`混淆）
- [ ] 取消其中一項不影響佇列裡其他項目的處理，佇列繼續往下走
- [ ] Orchestrator 的 `unittest` 測試：用一個可以被取消訊號中斷的假下載函式，驗證取消後該項目進入預期狀態，且下一個排隊項目正常開始處理
