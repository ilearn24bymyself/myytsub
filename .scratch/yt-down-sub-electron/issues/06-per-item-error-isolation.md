# 06: 下載佇列的逐項錯誤隔離

**What to build:** 下載佇列裡某一項失敗（一般性錯誤，不是限流），不會讓佇列裡排在它後面的其他項目跟著中止；該項目標記為 `error`，其餘項目照常繼續處理並各自完成。這是問題 2（一項失敗、整批連 index 都不會產生）的核心修正之一。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 一批多個下載項目中，讓其中一項（非第一項、非最後一項）的假下載函式丟出一般例外，驗證：該項標記為 `error`，前面已完成的項目維持 `done`，後面的項目繼續被嘗試且能正常完成為 `done`
- [ ] 失敗項目不會讓整支程式當掉或讓佇列卡住
- [ ] 這批次結束後，index 反映所有已到終態的項目（包含那個 `error` 的項目），不會因為有一項失敗就整批不產生 index
- [ ] Orchestrator 的 `unittest` 測試涵蓋上述情境
